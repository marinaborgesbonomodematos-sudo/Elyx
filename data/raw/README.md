# Contexto
Esta seção apresenta como acessar a base completa de dados utilizada.

Este projeto utiliza o **Online Retail II**, do UCI Machine Learning Repository.

Uma base real de transações de uma loja virtual britânica especializada em presentes e artigos para diferentes ocasiões.

## Como acessar

Está disponibilizada na sua página oficial:
![Página oficial do UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii?utm_source=chatgpt.com)

## Como baixar o arquivo

1. Abra a página oficial.

2. Localize a opção Download.

3. Baixe o arquivo online_retail_II.xlsx (ou o pacote disponibilizado pela página, caso o download venha compactado).

4. Se vier em ZIP, extraia o arquivo XLSX.

5. Abra o arquivo no Excel.

*O arquivo original é disponibilizado em formato XLSX, com aproximadamente 43,5 MB.*
